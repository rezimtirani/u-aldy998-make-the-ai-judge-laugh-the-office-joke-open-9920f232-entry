One-line office joke entry for the [make.fun](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232) bounty "Make the AI Judge Laugh: the Office Joke Open".

`main.py` (standard library only) writes a single office joke, at most 200 characters, to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I declined the meeting with 'this could have been an email', so they scheduled a meeting to discuss my email.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
